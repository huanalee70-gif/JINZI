Citadel LLC Gold 完整网站（手机适配最新版）
更新日期：2026年11月3日

一、包含内容
public：可编辑源码、图片和数据文件。
dist：可直接上传至静态网站托管平台的成品。
scripts：构建及本地预览脚本。
reference：原始参考文字。
asset-manifest.json：文件 SHA-256 校验信息。

二、直接部署
将 dist 文件夹内的全部文件上传至网站根目录。
确保 index.html 位于网站根目录，images 文件夹保持原有层级。
无需数据库，无需安装依赖。

三、本地预览
安装 Node.js 20.11 或以上版本（推荐22或以上版本）。
在包含 package.json 的项目目录打开终端，运行：
npm start
然后在浏览器打开：http://localhost:3000
不要直接双击 HTML 文件作为正式预览。

四、修改后生成
编辑 public/index.html，运行：
npm run build
更新数据文件时，也需同步修改页面内嵌的对应数据。

五、已完成优化
小字体与行距优化；手机导航及咨询入口；首页按钮纵向排列；
人物卡片、政策条款、行情区域、弹窗及联系表单的手机适配。
已在320、390、430px容器宽度检查横向溢出。

六、外部服务与限制
行情图表由 TradingView/OANDA 提供，需要互联网连接。
咨询表单只打开访客邮件应用中的草稿，不自动发送、不保存客户资料。
本压缩包不包含 ChatGPT 网站访问限制、账号、密码或部署凭证。
citadelgoldjp.com 尚未绑定至本网站；域名、DNS及HTTPS需在托管平台另行配置。
